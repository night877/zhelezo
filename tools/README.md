Сборка `exercises.js`: `python tools/build_db.py tools exercises.js`

- `sel.json` — исходные строки из Functional Fitness Exercise Database (свой вес, резины, блоки, турник).
- `ru.txt` — `индекс|русское название|крепление (n/m/f/h)|g` (g = гимнастика, по умолчанию скрыта).
- `custom.txt` — свои упражнения: `группа|название|крепление|инвентарь|техника`. Новые добавлять только в конец, иначе собьются id (c1, c2…) и история в дневнике.
