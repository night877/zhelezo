# ЖЕЛЕЗО — домашний журнал тренировок на резине

Мини-приложение для Telegram: конструктор тренировок, запись подходов, дневник с отчётами и статистикой. Оформлено в стиле журнала о бодибилдинге.

Сервер не нужен: это статичный сайт на GitHub Pages. Данные хранятся в облаке Telegram (CloudStorage), поэтому дневник доступен с любого устройства. Дополнительно они сохраняются в браузере.

## Что внутри

- **Конструктор.** 12 групп мышц, 542 упражнения на русском: резина и блоки на стенке, мини-резина, свой вес, турник и брусья, ролик, лавка. Есть поиск, избранное и свои упражнения. Для каждого указано, на какой высоте крепить резину.
- **Тренировка.** Два режима: мегасет (круги) и обычные подходы. Для каждого подхода записываются повторы и резина (можно отметить несколько). Есть таймер отдыха, а результат прошлой тренировки подставляется автоматически.
- **Дневник.** Календарь, тренировка оформлена как «выпуск журнала». В отчёте: упражнения, подходы, самочувствие и заметки. Текст для канала можно скопировать в привычном формате.
- **Статистика.** Подходы по мышцам за 30 дней, число тренировок за 12 недель, сколько недель подряд без пропусков, рекорды по упражнениям.
- **Ещё.** Программы (шаблоны), свои резины с цветами, инвентарь (лишнее можно скрыть), фото на обложку, резервная копия в файл.

## Как подключить к Telegram

1. В [@BotFather](https://t.me/BotFather) отправить `/newbot` и создать бота (или взять уже существующего).
2. `/mybots` → выбрать бота → **Bot Settings** → **Configure Mini App** (или **Menu Button**) → указать URL:
   `https://night877.github.io/zhelezo/`
3. Открыть бота, нажать кнопку меню — приложение запустится.

## Файлы

- `index.html`, `style.css`, `app.js` — приложение.
- `exercises.js` — база упражнений.

## Источник базы

Упражнения отобраны и переведены из [Functional Fitness Exercise Database](https://strengthtoovercome.com) (Strength to Overcome, v2.9), которая распространяется для личного некоммерческого использования. Ссылки на видео ведут на их YouTube-канал. Около 90 классических упражнений на резине и блоке добавлены отдельно, с подсказками по технике.
